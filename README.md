# 🌩️ Brickstorm

A modern Brick Breaker arcade game featuring dynamic gameplay, exciting challenges, and satisfying brick-smashing action.

## 🎮 About

Brickstorm is a browser-based arcade game inspired by the classic Brick Breaker. Control the paddle, bounce the ball, break bricks, and conquer challenging levels.

## ✨ Features

- Classic Brick Breaker gameplay
- Interactive ball and paddle mechanics
- Score and lives system
- Multiple levels
- Responsive UI
- Customizable themes and settings
- Progressive gameplay enhancements

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- HTML Canvas API
